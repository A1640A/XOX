## ELO — saf fonksiyon (`packages/db/src/elo.ts`)

```ts
export function eloDelta(ra: number, rb: number, result: EloOutcome): number {
  const expected = 1 / (1 + 10 ** ((rb - ra) / 400))
  const rawNewRating = Math.round(ra + ELO_K * (result - expected))
  const flooredNewRating = Math.max(rawNewRating, ELO_FLOOR)
  return flooredNewRating - ra
}
```

`Date.now()` yok, rastgelelik yok, `EloOutcome = 1 | 0.5 | 0`. Fonksiyon
YENİ puanı değil **DELTA**yı döner (`ra + delta` çağıranın yazdığı değer) —
taban kırpması yüzünden ham `ELO_K × (sonuç-beklenen)`den küçük olabilir.

**Determinizm kanıtı** (`elo.test.ts`, gerçek çıktı):

```
✓ SAFLIK: aynı üç girdi HER ZAMAN aynı çıktıyı verir (Date.now()/rastgelelik yok)
  → 5 ardışık çağrı, new Set(sonuçlar).size === 1
```

**Sınır testi (KK-110), gerçek çıktı:**

```
eloDelta(110, -1000, 0) === -10   (ham hesap -24 olurdu, ELO_FLOOR=100'e KIRPILDI)
110 + (-10) === ELO_FLOOR
```

**Nötr eleman körlüğü ÖNLENDİ** — K ve fark sıfır OLMAYAN vakalar ayrıca
test edildi: `eloDelta(1400,1000,1)===2`, `eloDelta(1000,1400,1)===22`,
`eloDelta(1400,1000,0)===-22` (favori/underdog asimetrisi, sabitten
türetilmedi, çıplak sayı). `10/10` test yeşil.

null}, …)` CAS'ından SONRA (yani yalnız yarışı KAZANAN çağrı için):


`getLeaderboardTop`in sorgusu KK-117'nin İSTEDİĞİ ŞEKİLLE BİREBİR:
`find({ratedGames:{$gte:LEADERBOARD_MIN_RATED_GAMES}}, 'name elo
stats').sort({elo:-1}).limit(limit)` — `users.elo` kısmi indeksinin
(`packages/db/src/models/user.ts`, DB-001) filtresiyle aynı. `getLeaderboardView`
`getFriendsView` ile aynı desende: `viewer` zaten `top`'ta ise `self:null`

**Explain sondası — GERÇEK `xox_test`e karşı, gerçek çıktı** (`leaderboard.test.ts`):

```
✓ KK-117: sorgu şekli find({ratedGames:{$gte}}).sort({elo:-1}).limit(N) —
  COLLSCAN YOK, ayrı SORT aşaması YOK
```

Bu test yorum değil — `plan = await User.find(...).sort(...).limit(...)
.explain('executionStats')`, ardından `JSON.stringify(plan)` içinde
`"COLLSCAN"` VE `"stage":"SORT"` metinlerinin OLMADIĞINI iddia ediyor.

**Paylaşımlı `xox_test` koleksiyonu riskine karşı önlem:** test kullanıcıları
`elo >= 500_000` gibi gerçekte ERİŞİLEMEZ değerlerle oluşturuluyor (gerçek
oyunla asla ulaşılamaz), böylece sıralama iddiaları başka test
dosyalarının/seed verisinin varlığından ETKİLENMİYOR — kendine-referanslı
değil, dıştan bilinen sabit değerlerle karşılaştırılıyor.

`getLeaderboardSelf`/`getLeaderboardView` için 12 test: eşik altı `null`,
var olmayan kullanıcı `null` (fırlatmaz), `rank = kendinden yüksek uygun
sayısı+1`, `top` içindeyken `self:null`, dışındayken `self` dolu ve doğru
