# DRY-004 — `errorJson`'ın SON iki kopyası (lead yürüttü)

**Tarih:** 2026-08-29 · **Yürüten:** lead · **Dalga:** gece koşusu #2, dalga 2

## Neden bu kart var

`DRY-003` ajanı işini bitirdikten sonra **dürüstçe bildirdi:** kartının "son üç kopya" başlığı
eksikti — `apps/web/app/api/leaderboard/route.ts` ve `apps/web/app/api/matches/route.ts` hâlâ
kendi yerel `errorJson` kopyalarını taşıyordu. Çakışma kümesinin dışında kaldıkları için
dokunmadı. Gerçek sayı **üç değil beşti.**

Bu, gecenin tekrar eden bir başka örüntüsü: bir kartın kapsamı, sorunun kapsamıyla aynı
olmayabilir. `DRY-002` "altı yer" demişti, `DRY-003` "son üç" dedi, gerçek kalan ikiydi.

## Değişiklik

Her iki dosyada da yerel `errorJson` silindi ve tek kaynağa (`apps/web/lib/http/error-json.ts`)
bağlandı. `ErrorCode` ve `ErrorResponse` import'ları **tamamen kaldırıldı** — ölçüldü, her iki
dosyada da bu tipler **yalnız** yerel `errorJson`'da kullanılıyordu:

```
leaderboard/route.ts : ErrorCode 2 geçiş, ErrorResponse 2 geçiş → ikisi de yalnız errorJson'da
matches/route.ts     : ErrorCode 2 geçiş, ErrorResponse 2 geçiş → ikisi de yalnız errorJson'da
```

## Davranış değişmedi — ölçüldü

Tek kaynak, silinen yerel kopyalarla **birebir aynı gövdeye** sahip:

```ts
export function errorJson(code: ErrorCode, message: string, status: number): Response {
  return Response.json({ code, message } satisfies ErrorResponse, { status })
}
```

Aynı komut, değişiklikten önce ve sonra:

```
pnpm --filter @xox/web exec vitest run \
  app/api/leaderboard/route.test.ts app/api/matches/route.test.ts

ÖNCE : 2 dosya / 13 test yeşil
SONRA: 2 dosya / 13 test yeşil     ← birebir aynı
```

## Kapanış — artık gerçekten kopya yok

```
git grep -c "^function errorJson" -- apps/web/app/api   →   SIFIR
```

`apps/web/app/api/**` altında tek bir yerel `errorJson` tanımı kalmadı.
