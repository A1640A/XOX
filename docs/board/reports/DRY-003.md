# DRY-003 — `errorJson` son üç kopya tek kaynağa bağlandı

## Kapsam

`DRY-002`'nin bıraktığı üç kalan kopya, tek kaynak `apps/web/lib/http/error-json.ts`'e bağlandı:

- `apps/web/app/api/profile/route.ts`
- `apps/web/app/api/friends/route.ts`
- `apps/web/app/api/auth/mobile/refresh/route.ts`

## `auth/mobile/refresh` şekil kontrolü (kart özellikle istedi)

Bağlamadan önce dosya okundu. Yerel `errorJson` gövdesi diğer ikisiyle **birebir aynıydı**:

```ts
function errorJson(code: ErrorCode, message: string, status: number): Response {
  return Response.json({ code, message } satisfies ErrorResponse, { status })
}
```

Tek kaynaktaki imza ve gövde ile tamamen örtüşüyor — kendine özgü bir hata şekli yok.
Karar: **zorlama gerekmedi, doğrudan bağlandı.**

## Yapılan değişiklik (üç dosyada aynı desen)

- Yerel `function errorJson(...)` tanımı silindi.
- `import { errorJson } from '@/lib/http/error-json'` eklendi (DRY-002'nin
  `auth/register`, `rooms`, `rooms/[code]`, `ws/ticket`'te kullandığı aynı yol/desen).
- Yalnız yerel `errorJson` içinde kullanılan `type ErrorResponse` importu artık kullanılmadığı
  için silindi (her üç dosyada). `ErrorCode` yalnızca `profile/route.ts`'te başka bir yerde
  (`fieldErrorCode`) kullanıldığı için orada tutuldu; `friends/route.ts` ve
  `auth/mobile/refresh/route.ts`'te `ErrorCode` başka yerde kullanılmadığı için o da silindi.
- Route gövdelerinin geri kalanı (durum kodları, `ErrorCode` değerleri, mesaj metinleri,
  try/catch akışı, `logError` çağrıları) **hiç değişmedi**.
